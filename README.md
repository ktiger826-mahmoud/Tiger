# TIGER – Mahmoud Amr Mahmoud

Personal contact card website, ready for GitHub Pages.

## Publish for free
1. Create a **public** GitHub repository named `tiger-card`.
2. Upload the contents of this folder to the repository root (keep `assets/tiger-photo.jpg`).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. The site URL will be `https://YOUR-USERNAME.github.io/tiger-card/`.

The QR code must be generated from the final published URL, not from a preview or local file.
